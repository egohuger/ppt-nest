# 安装与分发（Windows / macOS）

本文分两部分：**给使用者**（下载安装、首次打开会被系统拦怎么处理）和**给维护者**（两个平台怎么打包、发版流程）。

---

## 一、给使用者

### Windows

1. 下载 `PPT.Nest.Setup.2.5.0.exe`（约 135MB）。
2. 双击安装。用户级安装，**不需要管理员权限**，可以自定义安装目录。
3. 首次启动若弹出「Windows 已保护你的电脑」（软件未做代码签名，属正常）：点「更多信息」→「仍要运行」。
4. **建议本机装有 Microsoft PowerPoint**。没装也能用，但缩略图会退化为占位图，且只能解析 .pptx（旧版 .ppt 不支持）。
   - 替代方案：装 LibreOffice（免费，libreoffice.org），片巢在 Windows 上也会自动用它渲染。
5. 数据目录：`%APPDATA%\ppt-nest\data`（卸载不删，可在设置里改）。

### macOS

1. 下载 `PPT Nest-2.5.0-arm64.dmg`（**Apple 芯片**机型；Intel 机器见下方说明）。
2. 打开 dmg，把 `PPT Nest` 拖进「应用程序」。
3. 首次打开会被 Gatekeeper 拦下（软件未签名，属正常）。macOS 15 起**右键→打开已经失效**，现在只能这样：
   1. 双击 `PPT Nest`，弹出「无法验证开发者」→ 点「完成」；
   2. 打开「系统设置 → 隐私与安全性」，下拉到「安全性」区域；
   3. 点「仍要打开」→ 输入登录密码；
   4. 之后再双击就能正常启动（这个例外只记一次）。
   - 命令行替代：`xattr -dr com.apple.quarantine "/Applications/PPT Nest.app"`
4. **必须装 LibreOffice 才能出真实缩略图**（macOS 没有 PowerPoint 自动化接口）：
   `brew install --cask libreoffice`，或到 libreoffice.org 下载安装包。装完重启片巢即可。
   - 没装也能用：扫描、搜索、分类、去重都正常，只是缩略图是占位图，且旧版 .ppt 无法解析。
5. 数据目录：`~/Library/Application Support/ppt-nest/data`（卸载不删，可在设置里改）。

### 两个平台的能力差异

| 能力 | Windows | macOS |
|---|---|---|
| 缩略图渲染 | PowerPoint COM（需 Office）；没装则退 LibreOffice | LibreOffice |
| 旧版 .ppt / .pps 解析 | COM 或 LibreOffice | LibreOffice |
| 删除 .ppt 里的某一页 | 支持 | 不支持（先另存为 .pptx 再删） |
| 一键打开源文件 | 支持 | 支持 |
| 代码签名 | 无 | 无（仅 ad-hoc 签名） |

### 分发形式的现实提醒

- **安装包没有代码签名**：Windows 会弹 SmartScreen、macOS 会拦 Gatekeeper。给不熟悉电脑的人用，最好附一句提示（正文第 3 步），否则对方容易以为文件坏了。
- **GitHub Release 大文件在国内下载容易断**：建议同时给一个网盘备用链接（夸克/百度均可），或在下载页说明需要代理。
- **没有自动更新**：发新版后对方需要重新下载安装，不会自动升级。
- **软件要靠本机的 Office / LibreOffice 渲染**：分享前先问一句对方电脑里有没有 PowerPoint（Windows）或能不能装 LibreOffice（macOS）。

## 二、给维护者：打包与发版

前提：**PyInstaller 和 electron-builder 都不能跨平台**。macOS 包必须在 Mac 上打，Windows 包必须在 Windows 上打。

### macOS 打包（在 Mac 上执行）

```bash
cd <项目目录>
python3.14 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt pyinstaller
npm install
npm run build:mac        # = pyinstaller 出 dist-python/server + electron-builder 出 dmg
```

产物：

- `release/PPT Nest-<版本>-arm64.dmg` —— 对外分发件
- `release/mac-arm64/PPT Nest.app` —— 未压缩的 app（调试用）

开发态直接跑（不打包，改代码即时生效）：

```bash
PPTNEST_PYTHON=.venv/bin/python npm start
```

**Intel Mac**：当前 mac 包只出了 arm64。要支持 Intel，需要在 Intel 机器（或在 Rosetta 下的 x64 Python 环境）再打一次 x64，后端二进制同样必须重新编译成 x64。这一步目前没做。

### Windows 打包（回 Windows 机器执行）

```bat
cd <项目目录>
npm install
npm run build:win        :: = pyinstaller 出 dist-python\server.exe + electron-builder 出 nsis 安装包
```

产物：

- `release\PPT.Nest.Setup.<版本>.exe` —— 对外分发件（NSIS，用户级安装）
- `release\win-unpacked\` —— 免安装目录版（直接双击 `PPT Nest.exe`）

绿色版（免安装、拷 U 盘就能跑，适合发给朋友试用）：

```bat
python build-dist.py     :: 产出 release\PPT Nest\，整目录压成 zip 发出去
```

**坑**：打包前先退出正在运行的片巢，否则 `server.exe` 被占用，PyInstaller 报 PermissionError。

### 发版流程

1. 改 `package.json` 的 `version`（两个平台共用）。
2. 在 Mac 上 `npm run build:mac`，在 Windows 上 `npm run build:win`。
3. **两个产物各自打开验一遍**：装上后真扫一个 PPT 目录，确认缩略图是真实渲染图。
4. GitHub 建 Release、传两个安装包。大文件用浏览器在 Release 编辑页拖拽上传（命令行 `gh release upload` 在国内网络下会在 20MB 左右断）。
5. 更新本文档里的版本号，以及 README 的下载说明。
